# UI audit 2026-09-06 (interface engineer, per `docs/ui-audit-checklist.md`)

Walked the built app on the emulator (seed of `scripts/seed-emulator.mjs`) as
owner (chef@test.local) and crew (crew1@test.local) at 375×812 and 1280×800,
in `de` and `sq`. Measurements are DOM probes (`scrollWidth`,
`getBoundingClientRect`) taken in the Browser pane; the pane's screenshots
timed out for most of the walk, so every finding below carries the number
that proves it rather than a picture. Fixes are in
`docs/specs/2026-09-06_ui-audit-fixes.md`; product questions are listed at
the end, not fixed.

## Fixed in this pass

Spec `docs/specs/2026-09-06_ui-audit-fixes.md`, items 1–7 (findings 1–14),
plus the same local-date fix in the printed report's subtitle and note dates.
The tests that pin them:

- `render.test.mjs` (136): "a lazy tab shows a loading element while its
  chunk resolves" / "no loading element remains once the tab has landed";
  "Heute shows today's date with a weekday" / "the day's first action is a
  button in the day card" / "the day card comes before the weather"; "the
  Tagesrapport title is a local date, not an ISO key"; "breaks never read as a
  negative zero"; "a sent report row shows a local date"; "the Woche table pins
  its Total column"; "the Woche label is a local date range"; "the Cockpit's
  leave row wraps"; "phone tab bar labels carry no letter-spacing"; "the team's
  add-to-job select has an accessible name"; crew: "the Rapport shows the
  sent-reports empty state" / "a job without photos shows the photos empty
  state" / "the job sheet closes again".
- `logic.test.mjs` (300): `fmtDate` / `fmtMonth` / `fmtDateRange` for `de`,
  `en`, `sq`, `gsw`, an unknown language and non-dates; `printChrome` /
  `withPrintChrome` (window.print on load, the toolbar hidden on paper,
  escaping, placement); the existing "every language file has every key" and
  "is translated, not English" checks cover the ten new strings; the
  first-paint budget (358,023 of 358,400 bytes after this pass — the print
  chrome is a lazy chunk and the spinner ring lives in CSS to keep it there).

Verified on the emulator after the final build (service worker unregistered,
caches cleared): crew and owner Heute at 375 px (date, site, the action at
y≈330 without scrolling, min type 12 px); Woche in `de` and `sq` at 375 px
(table 437 px inside a 301 px box, Total and Datum pinned); the job hub's
photos empty state with the sheet at 690 px on every hub tab; Rapport titles,
rows and modal (no inner scrollbar, actions stacked, `overflow-x: hidden`);
the printed report document (toolbar, `window.print`, 44 px buttons); the
Cockpit leave row wrapped inside the card; the column scroll reset on a tab
switch; the update bar above the tab bar; 1280 px without horizontal
overflow.
